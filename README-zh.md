# Priv Kit

[![Maven Central](https://img.shields.io/maven-central/v/io.github.priv-kit/priv-core.svg?label=Maven%20Central)](https://central.sonatype.com/artifact/io.github.priv-kit/priv-core)

[English](./README.md)

Priv Kit 让 Android 应用通过 Root、ADB、手动命令或外部授权服务启动自己的特权进程。

让你的应用摆脱对 Shizuku 等独立授权应用的依赖。

- Binder 访问
- 文件操作
- 命令执行
- 自定义 UserService
- Android 输入事件注入
- Linux evdev 访问（实验性）

[阅读完整文档](https://priv-kit.netlify.app/zh/)

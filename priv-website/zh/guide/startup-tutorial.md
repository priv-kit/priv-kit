# 启动使用教程

先开启开发者模式，再选一种启动方式。

<a id="developer-options"></a>

## 1. 开启开发者模式

1. 打开 **设置 → 关于手机**，找到**版本号／OS 版本**，连续点击 **7 次**，按提示输入锁屏密码。
2. 回到设置，搜索并打开**开发者选项**；若有总开关，将它开启。

所有方式都需要；已开启可直接[选择启动方式](#choose-method)。

<details>
<summary>找不到版本号？按品牌查看</summary>

在设置中沿以下路径查找，连续点击最后一项 **7 次**。

**小米 / 红米**

关于手机 / 我的设备 → 详细信息与规格 / 全部参数 → **OS 版本 / MIUI 版本**

**OPPO / 一加 / 真我**

关于本机 / 关于手机 → 版本信息 → **版本号**

**vivo / iQOO**

系统管理 → 关于手机 → **软件版本号**（部分版本直接进入“关于手机”）

**三星**

关于手机 → 软件信息 → **编译编号**

**荣耀**

关于手机 → **版本号**

**华为（EMUI / HarmonyOS 4 及以前）**

关于手机 → **版本号**

菜单以手机实际显示为准。本教程不适用于 HarmonyOS 5 及以上。

</details>

<a id="choose-method"></a>

## 2. 选择启动方式

- **只用手机：**[无线调试](#wireless-debugging)，需要 Android 11 及以上和 Wi-Fi。
- **有电脑和数据线：**[手动启动](#manual)，无需下载工具。
- **遇到问题：**[常见问题](#faq) · [权限受限](#permission-restrictions)。

手机不支持无线调试时，选择手动启动。

<a id="adb"></a>

## ADB 启动

第一次用：先[开启开发者模式](#developer-options)，再按下方无线调试步骤操作。已配置端口的用户可跳到[静态端口](#tcp-ip)。

<a id="wireless-debugging"></a>

## 无线调试：只用手机

先完成[开启开发者模式](#developer-options)，再在这台手机上完成以下三步。

<a id="prepare-phone"></a>

### ① 打开无线调试

1. 手机连接 **Wi-Fi**。
2. 在**开发者选项**中开启**无线调试**，允许当前网络。

<a id="pairing"></a>

### ② 配对应用

1. 返回本应用，进入 **ADB → 配对**，允许通知权限。
2. 打开系统的 **无线调试 → 使用配对码配对设备**。
3. **保持配对码窗口打开**，下拉通知栏，在本应用的通知中输入六位配对码。

**没有通知？** 检查通知权限，或选择继续配对，用**分屏／小窗**同时显示系统配对窗口和本应用。

遇到问题：[一直搜索](#pairing-discovery) · [配对失败](#pairing-failed)。

<a id="start-and-confirm"></a>

### ③ 点击启动

返回本应用点击**启动**，看到服务**已连接**就完成了。

**配对后仍需点击启动。** [启动失败？](#start-failed)

<a id="manual"></a>

## 手动启动：需要电脑

准备电脑和一根**能传输数据的 USB 线**，无需下载工具。

**正在手机上看教程？Tango 要在电脑浏览器中打开。**

<a id="prepare-computer"></a>

### ① 连接手机

1. **手机：**先[开启开发者模式](#developer-options)，再开启 **USB 调试**，用数据线连接电脑。
2. **电脑：**用 **Chrome 或 Edge** 打开 [Tango](https://app.tangoapp.dev/)，按提示添加 USB 设备，选中手机。
3. **手机：**解锁并确认**允许 USB 调试**。只授权自己信任的电脑。

<a id="run-command"></a>

### ② 打开终端，执行命令

1. **电脑：**点击 Tango **顶部标签栏最右侧「＋」→ 终端**。
2. **手机：**在本应用的**手动**页点击**复制**，把命令传到电脑。
3. **电脑：删除开头的 `adb shell `，其余内容不变**，粘贴到 Tango 终端，按回车。
4. **手机：**返回本应用，看到服务**已连接**就完成了。

请用应用复制的完整命令；更新或重装后重新复制。

[连接或执行失败？](#computer-problems)

<a id="tcp-ip"></a>

## 进阶：静态端口

新手可跳过。已有可用的无线配对时，点击 **静态端口 → 启动**，按提示开启端口；若显示“通过无线调试打开静态端口”，也可使用。是否支持、端口是多少，以应用为准。

开启、重启或停止端口会中断其他 ADB 连接。只在可信网络使用；停止入口在**控制 → 停止**。配对端口不能当作静态端口。

Tango **终端**不能执行 `adb tcpip`。电脑配置需要支持静态端口配置的功能或工具；也可直接用上面的手动启动。

<a id="restart"></a>

## 下次怎么启动

- **仍已连接：**不用操作。
- **服务停止或手机重启：**恢复 Wi-Fi、开启无线调试，再点启动；手动方式则重新执行当前命令。
- **配对失效、重装应用或撤销授权：**再配对。不是每次重启都要配对，也不保证自动恢复。

<a id="faq"></a>

## 常见问题

按你遇到的情况检查：

<a id="missing-wireless"></a>

### 找不到无线调试

检查 Android 版本和开发者选项，搜索“无线调试”。系统不支持时，改用电脑手动启动。

<a id="pairing-discovery"></a>

### 一直搜索配对服务

连接 Wi-Fi，打开**使用配对码配对设备**窗口，不能只开无线调试开关。若提示本地网络权限，允许后重试；仍失败可重开配对窗口或换可信 Wi-Fi。

<a id="pairing-failed"></a>

### 配对失败／配对码不对

重新打开配对窗口，用**新的六位数字**，不是锁屏密码或端口号。输入时保持窗口打开，可用通知栏、分屏或小窗。

<a id="start-failed"></a>

### 无线调试或静态端口启动失败

无线调试先确认 Wi-Fi 和无线调试仍开启；静态端口按应用提示重新开启端口，再点**启动**。

**以上方法都无效时，最后尝试重启设备。** 无线调试配对失败或两种方式启动失败，都可以这样尝试。重启后重新连接 Wi-Fi，开启无线调试或静态端口，再配对或启动；仍失败时，把错误信息或启动日志发给应用维护者。

<a id="computer-problems"></a>

### Tango 连不上／命令执行失败

- **看不到手机：**用最新版 Chrome／Edge，检查 USB 调试、数据线和接口。
- **等待授权：**解锁手机，允许 USB 调试。
- **设备被占用：**关闭其他手机助手或调试工具；仍失败参阅 [Tango 连接排查](https://help.tangoapp.dev/features/troubleshooting/)。
- **提示找不到 adb：**删掉命令开头的 `adb shell `。
- **路径不存在：**重新从当前应用复制命令。

<a id="feature-failed"></a>

### 已连接，但功能不能用

出现“权限受限”时，查看下方对应品牌。仍有问题，把手机型号、系统版本和错误信息发给应用维护者；没有警告也不保证所有功能都被系统允许。

<a id="permission-restrictions"></a>

## 解决 ADB 权限限制

特权服务已启动，但修改应用权限、模拟点击等操作仍可能受到厂商系统限制。
请按设备系统查找以下设置。选项名称和位置可能随系统版本变化。

<a id="xiaomi"></a>

### 小米 HyperOS / MIUI

在**开发者选项**中开启 **USB 调试（安全设置）**。它与普通的“USB 调试”是两个不同的开关。
该选项的说明通常为“允许通过 USB 调试修改权限或模拟点击”。

<a id="coloros"></a>

### ColorOS（OPPO / OnePlus）

在**开发者选项**中关闭**权限监控**。

部分新版系统若在中文界面下找不到该选项，可尝试将系统语言切换为英文，
再进入开发者选项查找。按实际显示的名称操作：

- **Permission monitoring**：关闭。
- **Disable permission monitoring**：开启。
- 部分新版显示 **Disable system optimization**：开启。

实际提供的选项以当前系统版本为准。

<a id="oxygenos"></a>

### OxygenOS（一加海外版）

在**开发者选项**中开启 **Disable permission monitoring**（停用权限监控）。
部分新版将该选项显示为 **Disable system optimization**，同样需要开启。

<a id="realme"></a>

### realme UI（真我）

在**开发者选项**中开启 **Disable permission monitoring**（停用权限监控）。
部分版本可能不提供此选项。

<a id="vivo"></a>

### OriginOS / Funtouch OS（vivo / iQOO）

如果服务已经启动，但无法模拟点击，可在**开发者选项**中开启
**USB 模拟点击 / USB Simulated Input**（若当前版本提供）。
此设置针对输入控制，不代表能解除其他 Shell 权限限制。

<a id="flyme"></a>

### Flyme（魅族）

在**开发者选项**中关闭 **Flyme 支付保护**。
